# Patrones de error

Un error entra aquí **al segundo fallo**, no al primero: uno aislado es descuido, dos es un patrón.

Cuando un concepto llega a dominio alto, su fila baja a `## Superados`. La tabla activa se poda: si
crece sin parar, se deja de leer.
