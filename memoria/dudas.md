# Dudas para la docente

Aquí llega todo lo que ninguna fuente resuelve, y en particular las contradicciones entre una
diapositiva y el tablero. **No se resuelven solas**: se preguntan.

Una lección con una duda abierta se publica igual, marcada `con-dudas` y mostrando las dos lecturas.
El hueco se estudia, no se esconde.
